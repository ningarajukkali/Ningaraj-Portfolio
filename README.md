## ✨ Overview

Welcome to the repository of my personal developer portfolio — a high-performance, responsive, and visual web experience featuring custom 3D WebGL particle graphics, glassmorphic UI architecture, smooth interactive animations, and an official interactive resume viewer.

### 🌟 Key Highlights

- **🔮 Holographic 3D Data Orb**: Custom Three.js WebGL animation engine featuring a 6,000-particle Fibonacci sphere, 3 gyroscope orbital rings, and real-time mouse parallax physics.
- **📄 Interactive Resume &amp; PDF Engine**: Integrated resume showcase with interactive document view and direct PDF download.
- **🎨 Glassmorphic Aesthetic**: Deep dark space theme built using custom CSS tokens, glowing cyan &amp; violet gradients, and smooth micro-interactions.
- **📱 Ultra-Responsive**: Fully optimized for mobile, tablet, and high-resolution desktop screens.
- **⚡ Fast &amp; Lightweight**: Zero heavy bundle overhead — powered by Vite, HTML5, Vanilla JavaScript, and CSS3.

## ⚡ Quick Start &amp; Setup

### **Prerequisites**
- Node.js (v18+)
- npm or pnpm

### **Installation**

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ningarajukkali/Ningaraj-Portfolio.git
   cd Ningaraj-Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build production bundle**:
   ```bash
   npm run build
   ```
